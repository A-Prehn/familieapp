# App Store-materiale — Vores familie

Alt billedmateriale til App Store og hjemmesiden samlet ét sted.
Laves automatisk af workflowet **Skærmbilleder (demo-familie)** (`.github/workflows/ios-screenshots.yml`)
med den fiktive demo-familie (se `ios/Demo/README.md`). Kør workflowet igen, når appen ændrer udseende.

| Fil | Bruges til |
|---|---|
| `screenshots/6.9/*.png` (1320×2868) | App Store-skærmbilleder, iPhone 6,9" |
| `screenshots/6.3/*.png` | App Store-skærmbilleder, iPhone 6,3" |
| `header.png` (3840×1646) | App Store-header (produktsiden) |
| `og-image.jpg` (1200×630) | Delingsbillede — kopieret til `apps.prehn.net/vores-familie/og-image.jpg` |
| `review-paywall.png` | Review-skærmbillede af betalingsskærmen (skal fornyes til 1.1) |
| `app-store-da.md` | App Store-teksten |

Web-versionerne (WebP) til landingssiden ligger i PrehnApps-repoet: `vores-familie/img/`.
Billederne af demo-familien er fra Pexels (fri brug, ingen ansigter) — kilder i `ios/Demo/README.md`.
